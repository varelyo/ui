# Contributing

Open an issue to discuss API changes. Submit focused pull requests with passing checks and usage examples. Use English for source and documentation. Keep business logic in hooks, compose components from parts and derive visual prop types from tokens. Do not add explanatory source comments.

Files in src/generated, including the icon registry and the component token maps, are prebuilt by the maintainers. To add or change an icon, a component variant or a theme value, open an issue or a pull request with the source change, and a maintainer regenerates them. Preserve keyboard interaction, accessibility and the existing public API. Visual baseline changes require maintainer review.
